Cumulative Selection Explorer about and provenance

Cumulative Selection Explorer is the evo-edu public route for the Weasel-style cumulative-selection model family. The remediation pass now includes a direct responsive workbench using the shared artificial-life API while preserving the older Weasel route as a legacy reference.

Lineage

  • Legacy implementation directory: /apps/weasel/
  • Current launch target: /apps/weasel/weaselui.html

Current Limits

  • The new public workbench uses the shared artificial-life API and is designed for responsive public use.
  • The older Weasel-style route remains available as a legacy reference for comparison.
  • The tool is useful for model critique, but it does not by itself represent the full complexity of biological evolution.
