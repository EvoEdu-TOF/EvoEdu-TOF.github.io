Getting Started

What to do first

  • Randomize terminals and run the default search once.
  • Watch how best cost changes over generations.
  • Use the animation to compare earlier and later candidate networks.

Learner tasks

  • Change population size or mutation rate and compare the effect on best cost.
  • Switch to manual terminal placement and compare whether geometry changes what the search does well.
  • Explain why a good search strategy matters when there are many possible network layouts.

Core Question

How can iterative search produce lower-cost networks from the same set of points?

Scientific Virtues

Habits to practice

  • State clearly what the model demonstrates and what it does not claim about real systems.
  • Use repeated runs and comparisons as evidence instead of relying on one striking outcome.
  • Treat model limitations as part of the explanation, not as an afterthought.
