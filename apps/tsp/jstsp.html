Help

Usage:
1. (Optional) "Generate Cities" for random city placement.
2. Or "Define Cities Manually" to click-add them on the canvas.
3. Adjust GA parameters: Population, Selection %, 2-opt %.
4. Click "Start" to run the solver. You can pause with "Stop," or resume with "Resume."
5. The Loss plot shows best distance vs. generation, the Route plot animates each improvement, and the canvas draws the current best route in real time.

Click the X in the top-right or outside the box to close.

About

This TSP solver is a JavaScript/HTML adaptation of a GA-based approach originally detailed in A Fast TSP Solver using GA on Java by Hiroaki Sengoku. For more details, see the article: https://www.gcd.org/sengoku/docs/arob98.pdf .

Te motivation to implement this came when the common links found for the Java applet seemed to generally be non-functional.
