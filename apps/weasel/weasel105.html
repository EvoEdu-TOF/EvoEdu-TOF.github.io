Weasel Simulation

This interactive simulation demonstrates an evolutionary principle first popularized by Richard Dawkins. The idea is that repeated random mutation coupled with non-random selection converges on a target phrase much faster than mere chance alone. It’s often called the “Weasel” program, referencing Dawkins’ example phrase: METHINKS IT IS LIKE A WEASEL.

Use this page to explore how evolutionary processes can hone in on a specific “target” sequence. Even though the changes from one generation to another might be random, the “survival” and replication of the best matches drives the population toward that target.

Help

Target Phrase: Enter any phrase (letters A-Z, with spaces or punctuation if desired). The simulation will try to evolve a population of random strings into this target.

Population Size: How many candidate strings exist each generation. A larger population often converges faster, but requires more computation per generation.

Mutation Rate: The percent chance that each character in an offspring will mutate (change to a random character). Higher rates can introduce more variation but may slow convergence if too high.

Start Simulation: Begins evolving the population. You can watch the “Best Match So Far” update each generation.

Stop Simulation: Halts the ongoing run. You can then adjust parameters and start again.

About

This tool is provided as a resource for self-learners, students, and educators interested in exploring foundational concepts in evolutionary biology. By running this simulation and experimenting with parameters, you can see the power of incremental selection in climbing rugged fitness landscapes.

For more resources and explanations of evolutionary concepts, please visit Evo-Edu.org.
