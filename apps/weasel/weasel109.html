Weasel Program - Functional Approach

This simulation demonstrates how random mutation plus non-random selection can rapidly converge on a target phrase. Each generation, we mutate a population of candidate strings and pick the one that best matches the target. Below, you'll see a box plot of how many characters each candidate got “correct” in each generation, as well as the overall best match and any stepbacks in local best fitness.

Help

Target Phrase: Any phrase (A-Z, spaces, or punctuation). The simulation attempts to evolve a population of random strings to match this phrase.

Population Size: How many candidate strings exist each generation. Larger populations may converge faster but require more computation per step.

Mutation Rate (%): The percentage chance that each character in an offspring mutates to a random character. Higher rates can introduce more variation, but too much mutation can slow down convergence.

Start Simulation: Begins the iterative process of evolving the population. You will see the “Best Match So Far” and a box plot for each generation.

Stop Simulation: Cancels the evolution loop. You can then change parameters and start again.

About

This Weasel Program is inspired by a thought experiment from Richard Dawkins. It highlights how cumulative selection significantly outperforms pure chance in evolving a target sequence. It is especially useful for educators and self-learners exploring fundamental evolutionary concepts.

For more resources, see Evo-Edu.org.
