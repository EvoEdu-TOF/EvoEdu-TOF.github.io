* Introduction
This Org document contains the source structure for the Climate Range Shifter web app and its associated pages. It includes HTML content for the launch page, web app interface, instructions, exercises, curriculum alignment, and basic CSS and JavaScript.

* Files and Structure
- =launch.html= :: App launch page with navigation and cards.
- =webapp.html= :: The main interactive application.
- =instructions.html= :: Usage instructions and exercises for teachers and students.
- =alignment.html= :: Curriculum alignment with educational standards.
- =style.css= :: CSS for shared styling.
- =app.js= :: JavaScript logic for the web app.
- =Makefile= :: Automates tangling and building files.

* Usage Instructions for the Makefile
To build and deploy the web app files from this Org document:
1. Ensure you have Emacs with Org-mode and Babel enabled.
2. Save this file as =climate-range-shifter.org=.
3. Run `make tangle` to generate all HTML, CSS, and JS files.
4. Run `make install` to copy all generated files into the =dist= directory.
5. Open `dist/launch.html` in your browser to view the app.
6. Use `make clean` to remove the =dist= folder.

* Makefile
#+BEGIN_SRC makefile :tangle Makefile
# Makefile for tangling Org files and building the web app
ORG_FILE=climate-range-shifter.org
OUTPUT_DIR=dist

all: tangle

# Tangle all files from the Org-mode document
tangle:
	mkdir -p $(OUTPUT_DIR)
	emacs --batch $(ORG_FILE) \
	  --eval="(require 'ob-tangle)" \
	  --eval="(org-babel-tangle)"

clean:
	rm -rf $(OUTPUT_DIR)

# Simple target to copy tangling results into dist folder
install:
	mkdir -p $(OUTPUT_DIR)
	cp launch.html webapp.html instructions.html alignment.html style.css app.js $(OUTPUT_DIR)/
#+END_SRC
