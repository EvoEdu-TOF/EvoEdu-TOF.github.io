Curriculum Alignment

Evidence And Cause Workbench

Use this app wherever learners need to distinguish data patterns from causal explanations.

Aligned Practices

Analyzing and interpreting data

Learners classify observations, baselines, and evidence needs before writing causal claims.

Constructing explanations

Learners connect mechanisms to observed magnitude and identify alternative explanations.

Using models

Learners identify what each simplified scenario holds constant, what the model omits, and why that matters for real-world inference.

Argument from evidence

Learners revise overclaims into claims that name baselines, evidence, caveats, and any value language that has to be removed.
