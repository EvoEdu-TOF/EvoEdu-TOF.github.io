\section{Lab Handout: Matching Prototypes and Analysis}

This lab guides you step by step through running synthetic prototypes, exporting
data, and analyzing results. By the end, you will have both plots and metrics
that demonstrate strict matching, generalized matching, and gestalt constraints.

\subsection*{Part 1. Run Simulations}
\begin{enumerate}[leftmargin=*]
  \item Copy the provided Python scripts for:
    \begin{itemize}
      \item \textbf{A. Strict Matching (MLE)}
      \item \textbf{B. Generalized Matching (Sensitivity \& Bias)}
      \item \textbf{C. Gestalt Constraint (Limited Window)}
    \end{itemize}
  \item Execute each script in Python 3 (Anaconda, Miniforge, or Jupyter are
  fine). Each script will:
    \begin{itemize}
      \item Generate plots showing allocation patterns.
      \item Save CSV files with raw data (e.g., \texttt{strict\_matching\_mle.csv},
      \texttt{gen\_matching\_beta1p0\_bias0p0.csv}, \texttt{gestalt\_window\_W100.csv}).
    \end{itemize}
\end{enumerate}

\subsection*{Part 2. Analyze Results}
\begin{enumerate}[leftmargin=*]
  \item Run the helper script \texttt{analyze\_matching.py}.
  \item This script will print:
    \begin{itemize}
      \item \textbf{Part A:} Mean absolute error (MAE) between true $q$ and estimated $\hat{q}$.
      \item \textbf{Part B:} Regression slope (sensitivity $\beta$) and intercept (bias) for each curve.
      \item \textbf{Part C:} Convergence time to reach within $\pm 0.05$ of the new reinforcement rate after the switch, for each window size.
    \end{itemize}
  \item Confirm that the console output matches the expected patterns shown in class.
\end{enumerate}

\subsection*{Part 3. Report Deliverables}
Submit a short report (1--2 pages) including:
\begin{itemize}[leftmargin=*]
  \item The plots from Parts A, B, and C (saved as PNG or PDF).
  \item The CSV files generated by your code.
  \item A table summarizing:
    \begin{itemize}
      \item MAE for Part A.
      \item $\hat{\beta}$ (sensitivity) and bias estimates for Part B.
      \item Convergence times for each window size in Part C.
    \end{itemize}
  \item A short interpretation (3--4 sentences):
    \begin{itemize}
      \item How do your results illustrate \emph{allocation-grounding}?
      \item Where do you see signs of bias or undermatching?
      \item How does limiting the ``gestalt'' (context window) change the allocations?
    \end{itemize}
\end{itemize}

\subsection*{Part 4. Reflection Questions}
\begin{enumerate}[leftmargin=*]
  \item In what sense is the relation between reinforcement and allocation ``lawful''?
  \item How do the toy simulations relate to reinforcement histories in organisms?
  \item Which aspects of LLM training correspond to $\beta$, bias, and gestalt constraints?
  \item Why might these simplified experiments be useful before testing large-scale models?
\end{enumerate}

\subsection*{Grading Rubric (example)}
\begin{itemize}[leftmargin=*]
  \item \textbf{Plots:} 20 points (well-labeled, clear axes/legends).
  \item \textbf{CSV outputs:} 10 points (all files present).
  \item \textbf{Metrics table:} 20 points (correct values, neat summary).
  \item \textbf{Interpretation:} 20 points (links results to allocation- and gestalt-grounding).
  \item \textbf{Reflection questions:} 30 points (thoughtful answers, not just yes/no).
\end{itemize}

\textbf{Total: 100 points.}
