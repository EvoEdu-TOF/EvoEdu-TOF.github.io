Usage Instructions

Detailed documentation for each control, button behavior, input parameters, output expectations, and processing time estimates.

Exercises

Exercise 1: Predicting Range Shifts

Purpose: Understand how species respond to climate zone changes.

  • Methods: Use the time slider and temperature shift toggle
  • Data Gathering: Note latitudinal/longitudinal species positions over time
  • Data Analysis: Plot range centroids over time
  • Visualization: Use built-in map export
  • Conclusion: Determine thresholds for extinction or adaptation

Suggestions for Further Research

Explore interspecies interactions, altitude vs latitude migration, and dispersal limits.

Acknowledgments

This project was inspired by climate models and ecological simulations from leading researchers in biogeography.
