About This App

This web application demonstrates how to integrate the matpopdyn.js library (a JavaScript port of matpopdyn.py) with demographic matrices from COMADRE and COMPADRE, two global repositories of plant and animal matrix population models.

We acknowledge and thank the COMADRE/COMPADRE project teams for making these data openly available.

COMPADRE Plant Matrix Database (2025). Available from: https://www.compadre-db.org [23 February 2025, Version 6.23.5.0].

COMADRE Animal Matrix Database (2025). Available from: https://www.compadre-db.org [23 February 2025, Version 4.23.3.1].
